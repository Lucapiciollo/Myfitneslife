# MyFitAI — REAL PAGE ASSETS V2

Questo pacchetto contiene asset grafici separati realmente utilizzabili nelle Activity.
Non contiene screenshot di schermate da usare come UI.

## Usare come asset
- logo e leaf mark;
- background onboarding;
- decorazioni;
- corpo fronte/retro;
- avatar placeholder;
- immagini pasti;
- immagini allenamenti;
- illustrazioni categorie alimenti.

## NON rasterizzare
Devono restare componenti Material 3 reali:
- testi;
- card;
- bottoni;
- grafici;
- tab;
- chip;
- bottom navigation;
- toolbar;
- liste;
- metriche;
- progress indicator;
- checkbox/switch.

## Grafici
Costruire componenti data-driven:
- WeightTrendChartView
- BodyCompositionChartView
- ProgressChartView
- MiniProgressMetricView
- TimeRangeSelector

## Icone
Usare Google Material Symbols ufficiali/free, scegliendo variante, FILL, weight, grade, optical size, dimensione e colore coerenti col mock.
