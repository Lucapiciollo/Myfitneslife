# Design tokens da estrarre dal mock

Da consolidare prima dell'implementazione:
- palette background
- palette surface/card
- colore accent principale verde
- colore testo primario/secondario
- colori semantici positivo/attenzione/errore
- radius piccoli/medi/grandi
- spacing base
- altezze minime controlli
- tipografia H1/H2/body/caption/value
- elevation/ombre

Nota: i valori definitivi devono essere derivati dalla reference UI e centralizzati.
