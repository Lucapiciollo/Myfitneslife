# Checklist visiva obbligatoria

Per ogni schermata:
- background separato?
- componenti reali corretti?
- dimensioni coerenti?
- padding/margin/gap coerenti?
- font e pesi coerenti?
- radius coerenti?
- icone coerenti?
- colori coerenti?
- portrait coerente?
- landscape coerente?
- nessuna UI funzionale rasterizzata?
- confronto affiancato col mock eseguito?

Solo se tutte le risposte sono sì: Done.
